## IEPL香港是什么？和IPLC、普通香港BGP差在哪

IEPL（International Ethernet Private Line，国际以太网专线）是点对点的二层专属电路，数据走内网隧道，不经过公网拥堵路段。香港方向的优势首先来自物理距离：广州到香港的专线端内延迟约3毫秒；深圳和香港之间在运营商层面本来就有陆缆IEPL直连产品，所以深港方向的端内延迟能压到2毫秒左右。作为参照，普通CN2 GIA线路从内地到香港一般在10毫秒以上。

顺带把几个容易混的词分清：

- **IEPL**：以太网技术的国际专线，二层直连，延迟和抖动表现最好；
- **IPLC**：基于SDH的传统国际数据专线，HKT这类企业服务商两种都做，定位类似，技术上IEPL更新一些；
- **普通香港BGP**：走公网，价格便宜，但晚高峰拥堵和丢包是常态。

一句话概括：对延迟和稳定性敏感、访问方在内地、出口在香港的业务，IEPL是目前按月付费场景里值得优先考虑的方案。

## 企业级IEPL专线：另一个市场

如果你是企业采购、需要合同和SLA赔付，那么HKT、LittleBit这类服务商的IEPL和上面讲的按月套餐是两种东西，别放在一起比价。

HKT的IPLC和IEPL基于SDH及以太网技术构建，与内地多家运营商合作组网解决覆盖问题，配套CNMS系统可随时监控流量和可用性，还能和局域网方案打包成一站式交付。LittleBit给出的参数是抖动小于1ms、0%丢包、99.99% SLA，带宽从10Mbps弹性到100Gbps，主打高频交易、跨境结算和跨国组网。这类线路不挂公开价格，按年签约、报价制。

个人和小团队用不上这些，也不必纠结——按月的VPS式IEPL就是给这个人群准备的。反过来说，需要正规合同、发票和SLA的采购，别指望按月套餐能替代企业专线。

## 什么人不用买IEPL香港

三种人可以省下这笔钱：

- **客户全在海外**：IEPL的价值在内地入口。访问方不在内地的话，直接买香港BGP的普通VPS便宜得多，专线属于浪费预算。
- **纯轻量用途**：只是跑个博客后台、偶尔挂机，普通香港线路的延迟差距对体感影响有限，没必要为3毫秒付月费。
- **要SLA的企业采购**：MKCloud的公开资料里没有企业级SLA赔付条款，这类需求走传统专线渠道，或者先向商家确认能否满足。

## 香港IEPL常见问题

**延迟多少算正常？**
广港方向专线端内3毫秒左右，深港可以到2毫秒。测出来10毫秒以上，基本说明流量走了公网或者绕了路。

**共享带宽晚高峰会卡吗？**
有可能。共享模式保证的是峰值可达，不保证独占，晚高峰被挤是这种定价的固有代价。对卡顿敏感的业务，上独享是唯一彻底的解法。

**需要实名吗？**
需要。MKCloud要求中国身份信息实名，且仅限个人或企业正规用途。介意实名的话，这条线不用考虑。

**退款政策是什么？**
公开页面没有统一写明退款条款，下单前直接向客服确认，打算月付试水的用户尤其要问清楚。
